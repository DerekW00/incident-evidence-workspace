# Contributing

Use Python 3.12 and PostgreSQL 16, then follow the README's local setup. Work on a focused branch and describe the problem, resulting behavior and checks you ran.

For behavior changes, add a regression that demonstrates the problem, then run `make verify` and the relevant browser journey. Use synthetic fixtures; keep raw text untrusted, source citations inspectable, and tenant/worker publication boundaries intact. Documentation changes should preserve working relative links and accurate setup commands.

Keep third-party notices, disclose AI assistance where relevant, and report observed results accurately. Do not include credentials, private/customer data, fabricated history or unsupported production/model-quality claims.
